# Sweet Crumb Bakery Frontend

A React frontend for a bakery shop, built with Vite and set up for GitHub Pages deployment.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages hosting

This repository includes `.github/workflows/deploy.yml` which deploys the `dist/` build output to GitHub Pages on pushes to `main`.

In your repository settings, set **Pages** source to **GitHub Actions**.
